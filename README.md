# Data Pipeline to Recommendation System

## Overview
This project demonstrates a simple data pipeline that processes raw JSON data and generates recommendations.

## Steps
- Data Loading
- Data Cleaning (handling missing values, duplicates)
- Data Analysis (average rating, poor rating %)
- Rule-based Recommendation System

## Tech Stack
Python, JSON, basic data processing

## Output
- Cleaned dataset
- Insights like average rating
- Brand recommendations based on user ratings
